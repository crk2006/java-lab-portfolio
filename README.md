## ✨ Features

- **Glassmorphic Aesthetic:** Frosted glass cards (`backdrop-filter: blur`), subtle neon glowing borders, dynamic gradients, and smooth micro-interactions.
- **Theme Switcher:** Seamless Dark Mode / Light Mode toggle with `cubic-bezier` transitions.
- **Large Document Viewer:**
  - **Embedded PDF Viewer:** Displays the authentic submitted lab record PDF directly in an `<iframe>` with full scroll and zoom.
  - **Interactive Code Sheet:** Clean academic report view with syntax-highlighted Java code, problem descriptions, and formatted console outputs.
  - **Maximize / Full-Width Toggle:** Expands the Document Viewer across the entire container for an uninterrupted reading experience.
  - **Fullscreen Modal:** One-click modal viewer for both PDF documents and formatted code.
- **Complete 12-Week Dataset:**
  - **Week 1:** Comparative Study of Java, C, C++, Python & JavaScript
  - **Week 2:** JDK 25 Installation & Windows Environment Configuration (`JAVA_HOME`, `PATH`)
  - **Week 3:** Java Language Fundamentals (15 Foundation Programs)
  - **Week 4:** Object-Oriented Programming Fundamentals (Unit 2)
  - **Week 5:** String Handling, `StringBuffer` & `StringTokenizer`
  - **Week 6:** Inheritance Hierarchies, `super` Keyword & Dynamic Method Dispatch
  - **Week 7:** User-Defined Packages (`mypackage`, `college.*`) & Interfaces
  - **Week 8:** Robust Exception Handling (`try-catch-finally`, `throw`, `throws`, Custom Exceptions)
  - **Week 9:** Character Streams (`Reader`/`Writer`, `FileReader`/`FileWriter`) & File Word Counter
  - **Week 10:** Multithreading Priorities, Synchronization (Methods & Blocks), Inter-Thread Communication & Lambdas
  - **Week 11:** Java Collections Framework (`ArrayList`, `HashMap`, `HashSet`, Iterators)
  - **Week 12:** JDBC Database Connectivity, Prepared Statements & Streams API
- **Files Vault & Instant Downloads:**
  - Direct individual PDF download for each week.
  - **All-in-One ZIP Archive:** [`docs/All_Java_Lab_Records_Chandan.zip`](docs/All_Java_Lab_Records_Chandan.zip) bundling all 10 PDF records.
  - Interactive "Files Vault" modal listing all submitted PDFs with metadata and sizes.

## 🚀 Getting Started

No build tools, bundlers, or package managers required. Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/crk2006/java-lab-portfolio.git

# Navigate to project directory
cd java-lab-portfolio

# Open in browser (macOS)
open index.html

# Open in browser (Linux)
xdg-open index.html

# Open in browser (Windows)
start index.html
```
